# Step 8: save and export

## Save

Press `Ctrl+S` or pick *File › Save*. The first time, choose where to save it. A project is a `.creabim` file, which also keeps your undo history, so you can still undo after reopening it. See [Opening and saving](files).

## Print: PDF

*File › Sheets as PDF* writes every sheet as one PDF, ready to print or send. *File › This view or sheet as SVG* writes the open drawing as an SVG file.

## Share the model: IFC

*File › IFC4 (.ifc)* writes the model as an IFC file. Almost every BIM program can open it: Revit, ArchiCAD, Vectorworks, BlenderBIM (Bonsai), FreeCAD and many viewers. Walls stay walls, doors stay doors. See [IFC](ifc).

The exported files are written next to the project file, with the same name.
